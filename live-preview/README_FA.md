# پیش‌نمایش زنده نسخه ۵

این پوشه فقط برای پیش‌نمایش عمومی ساخته شده و بخشی از بسته نصب ایستگاه نیست.

- برنامه واقعی Flask فقط به `127.0.0.1:8001` متصل می‌شود.
- یک درگاه جداگانه و موقت روی `0.0.0.0:8080` درخواست‌های پیش‌نمایش را به برنامه محلی می‌رساند.
- هر بار اجرا، پایگاه داده نمونه و رمزگذاری‌شده جدیدی در `runtime/` ساخته می‌شود.
- هیچ داده واقعی ایستگاه خوانده نمی‌شود و نام افراد نمایشی است.
- ارسال واقعی به بله/ایتا، تغییر PIN و کانال‌ها، بازیابی، بروزرسانی و بارگذاری فایل در پیش‌نمایش مسدود است.
- ثبت مقدار نمونه، تغییر وضعیت موتور، دیدن هشدارها، چارت‌ها و ساخت PDF برای نمایش فعال است.
- CSS و JavaScript این پوشه فقط برای نمایش بهتر روی گوشی و جلوگیری از باز شدن پنجره مسدودشده PDF است.

اجرا در محیط توسعه:

```bash
python live-preview/run_preview.py
```

بسته نصب آفلاین همچنان برنامه را فقط روی `127.0.0.1:8000` اجرا می‌کند.
