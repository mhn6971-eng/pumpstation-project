# گزارش اصلاح بازبینی نسخهٔ ۱٫۴٫۵

## موارد اصلاح‌شده

- اصلاح آمار مستندات به ۷ پارامتر فرآیندی، ۱۹ شاخص موتور و ۸ موتور/پمپ.
- اعتماد به `X-Forwarded-Host` فقط وقتی `TRUST_PROXY=1` است؛ در حالت مستقیم از `Host` استفاده می‌شود.
- `flushQueue` وابستگی جاری `refresh` را می‌گیرد.
- `num()` مقدارهای `null`، `undefined` و رشتهٔ خالی/فاصله را رد می‌کند؛ `optNum()` همچنان برای ورودی اختیاری، null/خالی را به null تبدیل می‌کند.
- بازیابی بک‌آپ پیش از هر تغییر، حضور آرایهٔ تمام جدول‌های نسخهٔ جاری را بررسی می‌کند؛ بک‌آپ ناقص رد می‌شود تا داده‌ها مخلوط نشوند.
- پنل ست‌پوینت و سند مادر هشدار بهره‌برداری گرفتند.
- حذف نرم تجهیز دارای `safetyCritical` در سمت سرور رد می‌شود؛ بازهٔ نیمه‌پر کلاس رنگی مستقل گرفت.

## تصمیم مهندسی دربارهٔ جریان

پیش‌فرض‌های `currentWarn=120` و `currentCrit=140` عمداً تغییر نکردند. محاسبهٔ نامیِ یک مثال، جای پلاک واقعی، وضعیت اتصال، CT، روش اندازه‌گیری، شرایط بار یا تأیید مسئول برق/ابزار دقیق را نمی‌گیرد. این نرم‌افزار فقط پایش/هشدار می‌کند؛ مسئول مجاز باید مقادیر را پیش از بهره‌برداری تأیید و تنظیم کند.

## آزمون‌ها

- `npm run typecheck`: موفق.
- `npm run lint`: صفر خطا، ۱۱ هشدار موجود.
- `node scripts/generate-code-all.mjs`: موفق؛ شامل self-test و نصب تازه از بستهٔ تازه.
- آزمون نصب تازه: ۱۱۸ فایل استخراج، `npm ci`، مهاجرت ۰۰۰۰ تا ۰۰۰۵، build، health، وضعیت ۸ موتور/۱۲۴ تجهیز، و ۲۱۶/۲۱۶ سنجه.
- audit6: ۷۲/۷۲، شامل میزبان پروکسی، CSRF با هدر جعلی، عدد null، اعتبارسنجی snapshot و منع حذف تجهیز ایمنی‌حیاتی.
- `npm test` روی دیتابیس توسعهٔ موجود یک بار شکست خورد در دو تست نشست audit3 (`session.revoke` و `revoke_others`؛ نشست هدف پیدا نشد/401). این دو خطا به دادهٔ نشستِ محیط توسعهٔ ازقبل‌استفاده‌شده مربوط‌اند؛ آزمون مرجعِ نصب تازه با دیتابیس پاک، تمام مجموعه‌ها را سبز کرد.

## موارد بازِ عمدی

- پاک‌کردن خودکار فایل‌های `catalogs/trash`: حذف زمان‌دار بدون سیاست نگه‌داریِ تأییدشده، با قاعدهٔ عدم حذف فیزیکی تعارض دارد؛ فعلاً سطل بازیافت پاک‌سازی خودکار نمی‌شود.
- پاک‌سازی `AUX_TAGS`/`SAFETY_TAGS` استفاده‌نشده به‌عنوان refactor غیرعملیاتی عقب افتاد.
- رابط صریح پاک‌کردن توکن کانال هنوز پیاده‌سازی نشده است؛ توکن با غیرفعال‌کردن کانال پاک نمی‌شود.
