# پیش‌نمایش زندهٔ نسخه ۱.۲ — سامانه پایش ایستگاه پمپاژ زیرزمینی

این پوشه همان بستهٔ `pumpstation-v1.2-20261104-1227.zip` است که از پوشهٔ درایو پروژه گرفته شده و
برای اجرا در این محیط آماده شده است.

## چه چیزی برای اجرای پیش‌نمایش تغییر کرد؟

| مورد | توضیح |
|---|---|
| `src/db/index.ts` | دیتابیس به‌جای اتصال به سرور PostgreSQL، از **PGlite** استفاده می‌کند (همان PostgreSQL، ولی تعبیه‌شده و بدون نیاز به نصب سرور). نسخهٔ اصلی `pg` در همان فایل کامنت شده و برای سرور نهایی برگردانده می‌شود. |
| `drizzle/` | پوشهٔ مهاجرت‌ها که از `src/db/schema.ts` ساخته شد (جدول‌ها را از روی همان کد می‌سازد؛ هیچ چیز دستی اضافه نشده). |
| `scripts/init-db.mjs` | ساخت جدول‌ها در دیتابیس پیش‌نمایش؛ اجرای دوباره بی‌خطر است. |
| `next.config.ts` | `serverExternalPackages` برای PGlite و اجازهٔ دامنهٔ پیش‌نمایش (`allowedDevOrigins`). |
| `package.json` | اسکریپت‌های `preview` و `db:init`. |

هیچ فایل رابط کاربری، منطق یا استایلی دست‌کاری نشده است.

## اجرا

```bash
npm install
npm run preview      # init-db + next dev روی پورت 3000
```

اگر خواستید از صفر شروع شود، پوشهٔ `.data/` را پاک کنید تا دیتابیس و دادهٔ نمونه دوباره ساخته شود.

## ورود به سامانه (PIN پیش‌فرض)

- شیفت A (سعید شریفی، یزدان صفری) → `1111`
- شیفت B (جواد کاظمی، حسین طیبانی) → `2222`
- شیفت C (محسن نقی‌پور، یوسف نادری) → `3333`
- ادمین → `9999`

`docs/PROJECT_MASTER_FA.md` (سند مادر)، `docs/PROMPT_V1.2_FA.md` (پرامپت اجرایی نسخه ۱.۲) و

## اصلاحات امنیتی و پایداری (نسخه ۱.۲.۱)

پس از بازبینی فنی (`docs/AUDIT_v1.2_FA.md`)، فازهای ۱ و ۲ اصلاحات اعمال شد؛ شرح کامل در
`docs/HARDENING_v1.2.1_FA.md`. خلاصه:

- راز نشست اجباری و یکتا (`.data/session-secret`) — جعل کوکی ادمین ممکن نیست.
- قفل ۵ دقیقه‌ای پس از ۵ خطای PIN + ثبت همهٔ ورودها در `security_events`.
- نشست ۱۲ ساعته، ابطال با تغییر PIN و با خروج؛ دکمهٔ «خروج از همهٔ دستگاه‌ها» در سمت سرور آماده است.
- بک‌آپ خودکار روزانه (۳ تا ۵ بامداد) با چک‌سام در `.data/backups` و نگهداری ۳۰ نسخه.
- تراکنش دور عملیات چندمرحله‌ای + بازیابی دومرحله‌ای با تطبیق شمارش.
- ۱۶ ایندکس جدید، سقف ۲۵۶ کیلوبایتی بدنه، محدودیت نرخ نوشتن، ضدسیل هشدار.
- اعتبارسنجی تاریخ شمسی و محدودهٔ فیزیکی مقادیر، امن‌سازی آپلود PDF، هدرهای امنیتی.
- قفل خوش‌بینانه و همگام‌سازی تب‌ها.

```bash
npm run db:init     # اجرای مهاجرت‌ها (بعد از هر به‌روزرسانی کد لازم است)
npm run preview     # اجرای سامانه
```

## نسخه ۱.۳ — تاب‌آوری و نگه‌داری

| موضوع | افزوده‌ها |
|---|---|
| نشست | نشست سروری (`sessions`)، فهرست دستگاه‌ها، بستن یک دستگاه، خروج از سایر دستگاه‌ها، خروج خودکار پس از ۴ ساعت بی‌استفاده |
| ورود | قفل ماندگار در دیتابیس + رفع قفل توسط ادمین (`admin.unlock`) |
| ثبت | کلید یکتا (`Idempotency-Key`)، صف آفلاین مرورگر، تراکنش همهٔ عملیات چندمرحله‌ای |
| امنیت | بررسی مبدأ (CSRF)، سقف نرخ IP، شناسهٔ درخواست در خطاها، `app_events` |
| کارایی | ETag/304 برای وضعیت، ایندکس‌های تکمیلی، بایگانی داده‌های قدیمی با نمای ترکیبی |
| داده | خروجی CSV، سطل بازیافت تجهیزات، VACUUM از پنل، آمار بایگانی |
| فاجعه | `scripts/doctor.mjs`، قفل پوشهٔ داده، خاموشی تمیز، `reset-admin-pin.mjs` |
| مستندات | `docs/RUNBOOK_FA.md` (راهبری و بازیابی)، `docs/SECURITY_FA.md` (مدل تهدید و کنترل‌ها) |

```bash
npm test          # بررسی نوع‌ها + ۸۹ تست امنیتی/رفتاری
npm run doctor    # بررسی سلامت دیتابیس
```

## نسخه ۱.۴ — امنیت انتقال، دوعاملی، آینهٔ بک‌آپ، مسیر PostgreSQL

| موضوع | افزوده‌ها |
|---|---|
| ورود دوعاملی | TOTP بدون وابستگی (SHA-1/۳۰ثانیه/۶رقم، تحمل ±۳۰ ثانیه)، ۱۰ کد پشتیبان یک‌بارمصرف هش‌شده، پنل راه‌اندازی + بازنشانی گوشی گم‌شده |
| HTTPS | نمونهٔ آمادهٔ Caddy و nginx، کوکی `Secure` با `COOKIE_SECURE=1` یا `x-forwarded-proto`، HSTS فقط در حالت امن، راهنمای استقرار با چک‌لیست |
| آینهٔ بک‌آپ | کپی خودکار روی فلش/درایو/شبکه، تأیید با sha256 مبدأ و مقصد، سابقهٔ اجراها (`backup_mirror_runs`)، هشدار کهنگی، اسکریپت زمان‌بند با توکن محلی |
| دیتابیس | سوئیچ خودکار PGlite ↔ PostgreSQL با `DATABASE_URL`؛ `pg-init`، `pg-dump` (دامپ فشردهٔ روزانه) و `pg-import-json` (انتقال داده با بررسی هش) |
| پایش | `/api/health?full=1` حالا حالت دیتابیس، وضعیت آینه، مهاجرت‌ها و هشدارهای آن‌ها را هم می‌گوید |
| مستندات | `docs/DEPLOY_HTTPS_FA.md`، `docs/POSTGRES_MIGRATION_FA.md`، به‌روزرسانی RUNBOOK و SECURITY، `docs/PROMPT_V1.4_FA.txt` |

```bash
npm test                       # بررسی نوع‌ها + ۱۴۰ تست (audit1..audit5)
node audit/audit5.mjs          # فقط دوعاملی + آینه + هدرها + آمادگی HTTPS/PostgreSQL
node scripts/mirror-backup.mjs # کپی بک‌آپ روی آینه (برای Task Scheduler)
```
