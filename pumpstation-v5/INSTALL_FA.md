# راهنمای نصب خیلی ساده — ایستگاه پمپاژ

## ۱) نصب پایتون
روی کامپیوتر ایستگاه، پایتون ۳.۱۱ یا جدیدتر نصب کنید. هنگام نصب، گزینه Add Python to PATH را فعال کنید.

## ۲) اجرای برنامه
1. پوشه برنامه را روی کامپیوتر کپی کنید.
2. وارد پوشه `program` شوید.
3. روی `start.bat` دابل‌کلیک کنید.
4. صبر کنید تا مرورگر باز شود.

## ۳) اولین اجرا
1. یک رمز اصلی قوی وارد کنید.
2. تکرار آن را هم وارد کنید.
3. رمز را چاپ کنید و در محل امن فیزیکی نگه دارید.
4. سپس با PIN شیفت یا ادمین وارد شوید.

## ۴) نصب کاملاً آفلاین
اگر کامپیوتر ایستگاه اینترنت ندارد:
1. روی یک کامپیوتر اینترنت‌دار، پوشه `program` را باز کنید.
2. فایل `prepare-offline.bat` را اجرا کنید تا پوشه `wheels` ساخته شود.
3. کل پوشه برنامه را با USB به ایستگاه منتقل کنید.
4. در ایستگاه `start.bat` را اجرا کنید.

## ۵) بازیابی بک‌آپ
1. با ادمین وارد شوید.
2. بخش بک‌آپ و بازیابی را باز کنید.
3. فایل بک‌آپ را انتخاب کنید.
4. تایید کنید.
5. برنامه قبل از بازیابی، یک بک‌آپ ایمنی از وضعیت فعلی می‌گیرد.

## ۶) بروزرسانی
1. فایل ZIP بروزرسانی را از USB در صفحه ادمین آپلود کنید.
2. برنامه را ببندید.
3. دوباره `start.bat` را اجرا کنید.
4. بروزرسانی اعمال می‌شود و داده‌ها پاک نمی‌شوند.
